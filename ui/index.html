            Running jobs

            All jobs share the rate and usage limits of the same CLI logins and API keys. The jobs of a folder run beyond this limit wait in a queue and start in order as running jobs finish or pause; automatic retries wait for a free slot too.                   Setup

                  Checking…

                  The programs your models run through, and LaTeX for the PDF. TCS Prover checks them as jobs use them. Nothing is installed, updated or signed in until you confirm.

                  Jobs never wait for Setup: a job whose program is missing or signed out retries every minute and continues by itself once it works. “Signed in” means a login is saved; if it has expired, the job that needs it is listed under Needs your attention.

                  Setup never uses administrator rights, never asks for API keys, and keeps its output only on this page until TCS Prover restarts.

                  Each step's output keeps its newest 2,000 lines, and each check waits at most 20 seconds for a program to answer. Installs, updates and sign-ins have no time limit (in a Codex sign-in, each answer of the Codex CLI must come within 120 seconds); Stop ends them.
