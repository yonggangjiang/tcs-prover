## 6. Top 3 lessons from this window

1. **Resolving local sub-objectives substituted for progress.** Seven nodes and seven lemmas in 51 minutes, each "RESOLVED for its local objective" and each Conclusions section admitting the original statement is untouched (A039, A040, A041, A042, A043 all quoted above). The batch-1 audit's instruction "Do not open further nodes whose objective is to test one more fixed sampler, one more coupling rule, or one more static compression. Require every new node to name which of the two primitives above it would discharge" (audit-2:89) was re-read at 19:09:14 and 19:42:22 and then contradicted by A040 (static rounding), A042 (static certificate), A043 (fixed template). The harness should gate node creation on a one-line answer to "which top-level primitive does this discharge, and what is the shortest path from RESOLVED here to a full proof".
2. **The sufficient object was never minimized.** L007 needs only a random tree with p(δ⁺(S*)) < 3/2 for the optimal side; the author kept treating "sample from a packing" as "construct the packing (A019 load process), then sample". Neither the root nor the subagents ever wrote down the marginal-vector formulation in this window, although Audit-1's covariance remark (audit_history audit-1:44–58) and the author's own L063-style thinking were available. A forced periodic step — "state the weakest hypothesis the master reduction needs, then list ways to certify it that avoid the current machinery" — is the missing reflex; it would point at I4 (one tree, halve marginals per round) rather than at I9-style data structures.
3. **Compaction and pause overhead pulled effort into bookkeeping and repeated literature fetches, not re-planning.** ~35% of root commands in the window were recovery reads and index/promotion scripts; the same arXiv page was fetched ≥20 times because each subagent compaction wiped it. Recovery prompts told the author to "preserve the records and continue the same goal", which it did literally — it never re-evaluated the route. Persist a short "current hypothesis and its known obstruction" note that the compaction prompt requires the author to challenge, cache fetched sources in the workspace, and allow a paused turn to hand its live thread (here the 19:48 circulation/tree-extraction idea) explicitly to the resumed turn.
