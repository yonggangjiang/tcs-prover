## 1. Lemma-by-lemma

**Setup / polytope (pdf.txt:27–48, 124–138).** Claim: A_r = conv{1_T} = {x ≥ 0, x(δ⁻(v)) = 1 (v≠r), x(E(S)) ≤ |S|−1 (∅≠S⊆V)}. Verified: this is the face {x(δ⁻(v))=1, v≠r} of the branching polytope = graphic-matroid polytope ∩ in-degree partition-matroid polytope (Edmonds' matroid-intersection theorem); a branching with n−1 arcs and in-degree 1 at every non-root is an r-arborescence. Constraints with r∈S are redundant under (4) (x(E(S)) = |S|−1−x(δ⁻(S))), harmless. Cut form at line 132 (x(δ⁻(S)) ≥ 1 for r∉S) follows from x(δ⁻(S)) = |S| − x(E(S)). Nit: reference [1] (disjoint branchings, 1973) is not the source of the polytope description (Edmonds 1970 / Schrijver Cor. 52.3a); bibliographic only.

**Equation (7) (pdf.txt:154–181).** Verified: f^in has exactly one incoming arc (from e_{head(f)}^out, class (3)) and one outgoing arc (throughput), so that arc carries z_f; e_v^out has one incoming arc (throughput) and outgoing arcs only to f^in with head(f)=v (class (3)); conservation at e_v^out therefore gives z_{e_v} = Σ_{f∉T, head f=v} z_f, hence F(δ⁻(v)) = (1−z_{e_v}) + Σ z_f = 1. So (7) comes from conservation at e_v^out and f^in (not f^out), and uses no bounds — which is why it survives rounding. Corner case: if no non-tree arc enters v then z_{e_v}=0 is forced, requiring q_{e_v}=1; consistent, since every x∈A_r has x_{e_v}=1 and in the application c_{e_v} ≥ λ ≥ L. F(E)=n−1 ✓.

**Lemma 2.2 (pdf.txt:182–218).** Claim: if q ≥ x for some x∈A_r, the exchange network has a feasible circulation (for every T). Proof complete. Checked: z_e=1−x_e ∈ [1−q_e,1], z_f=x_f ∈ [0,q_f]; same-head outflow of e_v^out = Σ_{head f=v} x_f = 1−x_{e_v} by (4); transportation f^out (supply x_f) → e^in∈P_T(f) (capacity 1−x_e): for arbitrary A⊆E∖T, K=∪P_T(f) is a forest whose components are trees on X_i with |X_i|−1 edges, A∪K ⊆ ⊔E(X_i) with A∩K=∅, so x(A)+x(K) ≤ Σx(E(X_i)) ≤ Σ(|X_i|−1) = |K|, i.e. x(A) ≤ Σ_{e∈K}(1−x_e) (Hall); total supply x(E∖T) = (n−1)−x(T) = Σ_{e∈T}(1−x_e) = total capacity, so max-flow/min-cut saturates both sides; flows ≤ 1 ≤ n. The sentence "K contains all tree edges internal to those components" is true but not needed. Cor 2.3 ✓ (x_e ≤ min{1, c_e/λ} ≤ min{1,c_e/L} ≤ q_e).

**Lemma 3.1 (pdf.txt:233–264).** Claim: for ANY nonnegative circulation z on the exchange digraph with z_e ≤ 1 on tree arcs (q-bounds ignored), (1_T+F)/2 ∈ A_r. Proof complete. Nonnegativity from z_e ≤ 1; degrees from (7); T[S] connected: P_T(f) ⊆ T∩E(S) for internal f, conservation at f^out and at e^in plus nonnegativity give Σ_{f∈E(S)∖T} z_f ≤ Σ_{e∈T∩E(S)} z_e, so F(E(S)) = (|S|−1) − Σz_e + Σz_f ≤ |S|−1 = 1_T(E(S)) (covers |S|=1, E(S)=∅); T[S] disconnected: |T∩E(S)| ≤ |S|−2 and F(E(S)) ≤ Σ_{v∈S}F(δ⁻(v)) ≤ |S|, average ≤ |S|−1. The q-freeness stated at 231–232 is essential (see Section 4). Sanity example: T={(r,a),(r,b)}, non-tree (a,b),(b,a), z≡1 gives F = the 2-cycle ∉ A_r, but (1_T+F)/2 = ½(1_{{(r,a),(a,b)}} + 1_{{(r,b),(b,a)}}) ∈ A_r — Remark 3.2 in action.

**Section 4 rounding + decomposition (pdf.txt:267–296).** Verified: throughput bounds [⌊z⌋,⌈z⌉] ⊆ [0,1] since z_e∈[1−q_e,1], z_f∈[0,q_f]; discarding q-bounds is forced (an unbiased rounding of z_e∈(1−q_e,1) must output 0 with positive probability, lines 275–277), and this is exactly why Lemma 3.1 had to be q-free. B∈{0,1}^E ✓. One incoming arc per non-root vertex: (7) for the integral Z gives (1−Z_{e_v}) + Σ_f Z_f = 1 with all terms in {0,1}, so exactly one is 1 ✓. E[B|T,z]=F ✓. (1_T+B)/2 ∈ A_r ⇒ |δ⁻_H(S)| = 2·((1_T+B)/2)(δ⁻(S)) ≥ 2 for r∉S ⇒ Edmonds gives two arc-disjoint arborescences; |H| = 2(n−1) so they partition H (duplicated arcs handled at line 295) ✓. Citation [2] verified by web search: Tarjan 1976 (Acta Inf. 6:171–185) is precisely an algorithm for two edge-disjoint spanning trees rooted at a fixed vertex of a directed graph in O(e·α(e,n)) time — the exact k=2 instance needed, costing O(n·α) on H. (Gabow 1995's O(λm log(n²/m)) / O((kn)²) bounds are not needed.)

**Lemma 4.1 (pdf.txt:297–315).** E[1_{T'}|T,z,Z] = (1_{A_1}+1_{A_2})/2 = (1_T+B)/2 by the partition; expectation over rounding gives (1_T+F)/2 ≤ (1_T+q)/2 pointwise in z, so any randomness in choosing z is irrelevant (312–313) ✓. Cost: one circulation-with-lower-bounds = one maxflow via the standard reduction on O(m log² n) arcs, rounding O(M log m), decomposition O(n·α) ✓.

**Lemma 5.1 (pdf.txt:325–353).** Verified: HLD keys each tree edge by its child vertex, P_T(f) = O(log n) heavy-path intervals with the lca's parent-edge position excluded (correct), each interval = O(log n) canonical segment-tree nodes ⇒ O(m log² n) arcs. Direction 1: route f^out → canonical node ⊇ pos(e) → down → leaf(e) → e^in; total gadget flow = Σ_f z_f = Σ_e z_e ≤ n−1 (uses z_e ≤ 1) ≤ capacity n. Direction 2: gadget arcs (f^out→canonical, parent→child, leaf→e^in) form a DAG, so the restricted flow decomposes into f^out→e^in paths; a path from f^out enters a canonical node covering a sub-interval of P_T(f) and can only descend to leaves inside it, so it ends at some e∈P_T(f); replacing paths by uncompressed arcs preserves throughputs and conservation. Rounding on the compressed network is legitimate: Lemma A.1/Kang–Payor is applied to the compressed circulation and returns an integral compressed circulation Z̃; its throughputs Z are in {0,1} with E[Z]=z; (7) uses only same-head and throughput arcs, which compression leaves untouched; Lemma 3.1 needs some nonnegative uncompressed circulation with throughputs Z, supplied existentially by Direction 2. The "Implementation requirement" paragraph (351–353) says exactly this. Complete.

**Lemma 6.1 / 6.2 and constants (pdf.txt:363–412).** 6.1: tower property, p_{t+1} ≤ (p_t+q)/2, induction (checked t=0,1 and the step) gives (1−2^{-t})q + 2^{-t}1_{T_0}; needs feasibility for every tree in the support, which Lemma 2.2 gives for every T ✓. **Lemma 7.1 (pdf.txt:423–454).** Verified: the per-layer network (shared s,t; arcs into C from outside become s→v; v_C→t with capacity M_0 > total) computes min{c(δ⁻(R)) : v_C∈R⊆C} for all components at once; at the first layer removing a vertex of W, W lies in one component C (T[W] connected, no removed vertex in W) and v_C∈W, so a candidate of value ≤ λ appears; every candidate is a nonempty root-excluding set so ≥ λ; O(log n) layers ⇒ O(log n) maxflows on O(m+n) arcs ✓. **Appendix A (pdf.txt:516–534).** Verified: h=2^b z integer; odd-arc subgraph has even degrees (conservation mod 2) ⇒ Euler cycle decomposition; the signed unit cycle is a circulation (each cycle vertex gets net +1 in and +1 out regardless of arc orientations); ±1 with probability ½ makes odd entries even, keeps nonnegativity (odd ⇒ ≥1), preserves expectations; b rounds of O(M). ## 4. New vs standard; the pivot
Standard: I0 (Edmonds polytope), I1 (Cen et al. 2021), I2 (Markov), I3 (Edmonds 1973), I7 (Euler-tour bitwise rounding / Kang–Payor), I8's theorem and algorithm (Edmonds 1973, Tarjan 1976), I9 (HLD × segment tree range-arcs; the agent's binary-lifting version likewise standard), I10 (geometric guessing), I11 (Chen et al.).
New as an assembly: I4 (maintain one tree, target marginals q, halving update, O(log n) iterations), I5 (bounded exchange network whose feasibility follows from mere existence of a dominated polytope point), I6 (half-step lemma), and the USE of I7+I8 as a coupling that realizes the fractional half-step as one random arborescence.
Single pivot: I6, Lemma 3.1 — (1_T+F)/2 ∈ A_r for every circulation on the exchange digraph. It is the only new mathematical fact; it declares that F need not be a tree or even a valid simultaneous exchange (the exact obstruction the agent recorded in L034 and, by title, in L035/L036), so the update can be a single flow (degree and fundamental-path constraints are flow-expressible; the exponentially many cut constraints are not, and the averaging with T supplies them for free), and its integral instance is precisely Edmonds' hypothesis for T+B, which is what makes a random single tree T' with E[1_{T'}|T] = (1_T+B)/2 exist. Remove I6 and I5 yields a possibly cyclic F, I7 a cyclic B, no decomposition, and I4 has no step. I4 is the indispensable frame that makes a factor-½ step sufficient rather than a loss, but it is the natural wish once one decides not to construct the packing; I6 is the realization that the wish is a theorem.
